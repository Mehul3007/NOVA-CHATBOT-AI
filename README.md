# NOVA AI – Advanced Gemini-Powered Chatbot

NOVA AI is a modern, feature-rich AI chatbot built with HTML, CSS, and JavaScript, powered by Google's Gemini 2.5 Flash model. It provides a sleek dark-themed interface, real-time AI conversations, voice interaction, file uploads, chat management, and productivity tools in a responsive web application.

## ✨ Features

* 🤖 Gemini 2.5 Flash Integration
* 💬 Real-time AI Chat Interface
* 🌙 Modern Dark Theme UI
* 🎤 Voice Input Support
* 🔊 Text-to-Speech Responses
* 📎 Image & File Upload Support
* 📝 Markdown Rendering
* 💻 Syntax Highlighting for Code Blocks
* 📂 Project Management Section
* 🕒 Chat History Management
* ⚙️ Customizable Settings Panel
* 📤 Export Chat Conversations
* 🗑️ Clear All Chats Option
* 📱 Fully Responsive Design
* 🚀 Fast and Lightweight Performance
